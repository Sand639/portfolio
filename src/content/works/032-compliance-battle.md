## 概要

- ジャンル: ローカル対戦
- 開発環境: Unity 6000.3.14f1（URP）
- プレイ人数: 2人（1台の PC・1つのキーボード）

HAL東京 4年生の学内ゲームジャム（4回目）で制作した作品です。

中指を立てて本数を当て合い、先に両手を消したほうがゲームを取ります。先に2ゲーム取ったほうが勝ちです（3本勝負）。

## 遊び方

| 操作 | プレイヤー1（左） | プレイヤー2（右） |
|---|---|---|
| 左手の中指を立てる（押している間） | A | ← |
| 右手の中指を立てる（押している間） | D | → |
| スキルを使う | W | ↑ |

| 操作 | キー |
|---|---|
| 本数を宣言する（自分の番・画面には出ない） | 0〜4（テンキー可） |
| 「いっせーの」 | Space |
| モザイクのあり / なし | M |
| 勝負がついたらタイトルへ | Enter |

1. 番のプレイヤーが数字キーで本数を宣言し、Space で「いっせーの」
2. 「いっせーの ＜数字＞！」の瞬間に立っている中指の合計が宣言と同じなら当たり。番のプレイヤーの手が1つ消える
3. 当たってもはずれても番を交代。両手とも消えたらそのゲームを取る

## スキル

試合の始めにランダムで1つ配られ、当てられた側がもらえます。

| スキル | 効果 |
|---|---|
| コンクリ | 下がっている相手の指を、次の自分の番まで上げられなくする |
| セメント | 上がっている相手の指を、次の自分の番まで下げられなくする |
| イーブン | 合計が偶数なら当たり |
| オッズ | 合計が奇数なら当たり |
| ピース | 2を宣言して当たれば、そのゲームに即勝ち |
| サンダー | 3を宣言して当たれば、そのゲームに即勝ち |
