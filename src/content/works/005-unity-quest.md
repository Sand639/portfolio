## 概要

- ジャンル: 2.5Dアクション
- 開発環境: Unity 2021.3.23f1
- 使用言語: C#

HAL東京の Unity ゲーム制作専科の講義動画を見ながら制作した作品です。

## 操作方法

| キー | 操作 |
|---|---|
| A / D | 左 / 右に移動 |
| Z | ため攻撃 |
| マウス左 | 通常攻撃 |
| マウス中央 | 回避 |
| マウス右 | 防御 |

## 制作について

C# を学びながら、他の言語にも通じるプログラムの組み方、コーディングの仕方、バグの直し方、Unity の基本操作をひととおり学びました。自分のプログラミングの基礎になった作品です。

## 学んだこと

- bool の考え方と C# の基本
- アセットの導入方法
- Unity での 3D ゲームの作り方
- 音の鳴らし方、エフェクトの出し方
- UI の作り方、アニメーションの付け方
