## 概要

- ジャンル: 2Dシューティング
- 開発環境: Visual Studio 2022 / DirectX 11
- 使用言語: C言語 / C++
- 対応コントローラー: Joy-Con、DUALSHOCK（キーボード・マウスでも操作可）

プレイヤーを操作して弾を撃ち、敵を倒します。敵を倒すとプレイヤーの体が大きくなります。体が0になるとゲームオーバーなので、気を付けながらボスの撃破を目指します。

## 操作方法

| 操作 | コントローラー | キーボード |
|---|---|---|
| 向きを変える | 左スティック | A / D |
| 通常攻撃 | 右側の西ボタン | Space |
| しっぽ攻撃（LEVEL1 以上） | 右側の東ボタン | Q |
| ブレス攻撃（LEVEL2 以上） | 右側の北ボタン | U |
| 選択 / 決定 | 左スティック / 右側の南ボタン | W・A・S・D / Enter |

## 制作について

チーム制作の案が1つに絞られ、この「登龍門」をチーム全体（13人）で制作することになりました。このプロジェクトでチームに GitHub を広めて導入し、ブランチを分けて作業する本格的なチーム制作が始まりました。同じスクリプトを複数人で触ると競合が起きるため、機能ごとにクラスを分けるオブジェクト指向の大切さを実感しました。

敵を多く制作したため、スプライトアニメーションの技術が特に伸びました。工夫した点は次のとおりです。

- 桜井政博さんの YouTube チャンネルを参考に、指定したテクスチャが描画されるまで次のアニメーションと行動に遷移しないようにして、違和感のないアニメーションの切り替えになっています。
- イージング関数で攻撃に緩急を付けた

## 担当
