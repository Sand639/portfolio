## 概要

- ジャンル: アクション
- 開発環境: Visual Studio 2022（Nintendo Switch 開発機）/ OpenGL
- 使用言語: C言語 / C++

## 制作について

Nintendo Switch の開発機を使った制作です。ブレークポイントが反応しない、六軸センサーの値がうまく取れないなど、開発機に慣れていないことによる問題で時間がかかりました。

最終的にはコントローラーを振って敵をなぎ倒していくゲームを目指していましたが、規模を絞ったミニゲームとして完成させました。この制作で UV 座標を動かす表現が得意になりました。
