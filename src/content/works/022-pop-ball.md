## 概要

- ジャンル: 3Dアクション
- 開発環境: Visual Studio 2022 / DirectX 11
- 使用言語: C言語 / C++

## 操作方法

操作方法はゲーム内のビルボードにも表示されます。

| キー | 操作 |
|---|---|
| W / A / S / D | 矢印の向きを調整 |
| 矢印キー | 視点を移動 |
| Space | ボールを発射 |
| R | 復活地点へテレポート |
| Q / E | 視点を拡大 / 縮小 |
| U | UI の表示・非表示 |
| I | ビルボードの表示・非表示 |
| Esc | ポーズ画面 |

開発者用: 数字キー 1〜5 でそれぞれの復活地点の座標を保存し、R でテレポートできます。

## ブロックの種類

| 色 | 名前 | 効果 |
|---|---|---|
| 黒 | ブロック | 普通の足場 |
| 緑 | リスポーンブロック | 触れると復活地点を更新 |
| 青 | ムーブブロック | 平面上を移動する足場 |
| 桃 | ゼロタイムブロック | 触れた瞬間に発射のクールタイムがなくなる |

## 制作について

DirectX11で3Dゲームを作る授業で作ったものをベースに、ステージとビルボードを作成し、ギミックを新しく追加して遊べるようにした作品です。DirectX で 3D ゲームを作るうえでの大きな一歩になりました。

アピールポイント: 動く足場、リスポーンブロック、ボールを追いかけるカメラ。
