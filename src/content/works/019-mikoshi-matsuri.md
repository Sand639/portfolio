## 概要

- ジャンル: 3Dレース
- 開発環境: Visual Studio 2022 / DirectX 11
- 使用言語: C言語 / C++
- プレイ人数: 2人
- 状態: プロトタイプ（別プレイヤーとの競争は未実装）

Joy-Con を上下に振って神輿を前に進ませ、障害物を避けながら別のプレイヤーと競争するゲームです。

## 操作方法

| 操作 | 内容 |
|---|---|
| Joy-Con を振る | 前に進む |
| ↑ / ↓ | 神輿を上げる / 下げる（この動作で神輿が前に進む） |
| Enter | 弾を発射 |

## 制作について

13人のチームで、課題としてプロトタイプを3つ提出する必要があったため、3チームに分かれて制作しました。ブレインストーミングで残った案のうち、先生の許可が出た案でプロトタイプを作ることになりました。

3D の授業と並行していたため、3D モデルの読み込みと操作に苦労しました。また、コントローラーが Joy-Con に決まったことで GitHub 上のライブラリ（JoyShockLibrary）を使うことになり、英語のコードを読み解きながら導入しました。

このチームの案は最終的に採用されず、チーム全体で「[登龍門](../024-toryumon/)」を制作することになりました。
