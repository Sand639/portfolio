## 概要

ゾンビにやられずに森（テレインの端）まで抜け出せたらクリアです。

## 操作方法

| キー | 操作 |
|---|---|
| W / S | 前進 / 後退 |
| A / D | 左 / 右に曲がる |
| 移動 + Shift | ダッシュ（歩きの3倍の速さ） |
| Space | ジャンプ |
| 左クリック | 射撃 |
| 右クリック | エイム |
| Esc | マウスカーソルを表示 |

## 工夫した点

- マウス操作でカメラの向きを回転させ、カメラの向きに合わせてプレイヤーの向きを変えるTPSの視点を実装しました
- カメラが上や下を向きすぎないように角度を制限しています
- 処理が重くならないよう、敵はプレイヤーの周りにだけ出現させています

## 苦労した点と解決

カメラの挙動の実装に時間がかかり、ゲーム本体の作り込みまでは至りませんでしたが、TPS ゲームの基礎を学べました。

## 学んだこと

- マウスとカメラの制御
- マウスカーソルの表示・非表示
- テレインの使い方
